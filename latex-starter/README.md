# مولّد قوالب لاتك — LaTeX Starter

أداة محلية تولّد مقدمة وثيقة LaTeX جاهزة للترجمة بالإنجليزية أو العربية أو متعددة اللغات، مع نسخ وتنزيل `.tex` أو مشروع ZIP متعدد الملفات.

**منتج هندسة عكسية**: هذا التطبيق مُرحَّل من مشروع Next.js 16 + React 19 + TypeScript + Tailwind 4 إلى **HTML + CSS + JavaScript نقي** — بلا إطار عمل، بلا خطوة بناء، ومكتبته الوحيدة JSZip موردة محليًا، ويعمل بفتح الملف مباشرة في المتصفح.

## بنية المشروع

```
latex-starter/
├── index.html                # الصفحة الرئيسية (نقطة الدخول — في المسار الرئيسي)
├── assets/
│   ├── css/
│   │   ├── style.css         # التنسيق الأساسي: المتغيرات والعناصر والمكونات
│   │   └── responsive.css    # تنسيقات الشاشات المختلفة (الموبايل والتابلت)
│   ├── js/
│   │   ├── main.js           # البيانات + مولّد LaTeX + الواجهة والتفاعلات العامة
│   │   ├── utils.js          # دوال مساعدة عامة (تنظيف أسماء الملفات، escapeHtml، التنزيل، الحافظة)
│   │   └── vendor/
│   │       └── jszip.min.js  # مكتبة JSZip 3.10.1 موردة محليًا لبناء ZIP دون اتصال
│   └── images/
│       └── favicon.svg       # أيقونة تبويب المتصفح
└── README.md                 # هذا الملف
```

ملاحظة: الخطوط (IBM Plex Sans Arabic وJetBrains Mono) تُحمَّل من Google Fonts، فلا حاجة لمجلد `fonts/` محلي؛ وإن رغبت بالعمل دون اتصال نزّل الخطوط إلى `assets/fonts/` وغيّر الوسم في `index.html`.

## التشغيل

1. افتح `index.html` مباشرة في المتصفح — أو أي خادم ملفات ثابتة مثل `python3 -m http.server` من مجلد المشروع.
2. اختر الإعدادات من الأقسام السبعة، وستتجدد المعاينة تلقائيًا.
3. انسخ الكود، أو حمّل ملف `.tex`، أو مشروع ZIP عند اختيار «مشروع متعدد الملفات».
4. للنسخة المدمجة بملف واحد (CSS وJS داخل الـ HTML): استخدم `latex-starter.html` في المجلد الأعلى.

## التطوير (إعادة البناء)

مصادر الحقيقة في `scripts/ls_parts/` خارج هذا المجلد:

| المصدر | الناتج |
|---|---|
| `ls_utils.js` | `assets/js/utils.js` |
| `ls_data.js` + `ls_generator.js` + `ls_ui.js` | `assets/js/main.js` |
| `ls_style.css` | `assets/css/style.css` |
| `ls_responsive.css` | `assets/css/responsive.css` |

عدّل المصدر ثم شغّل:

```bash
python3 scripts/build_latex_starter.py
```

السكربت ينسخ الأجزاء إلى مساراتها في `assets/` وينتج النسخة المفردة `latex-starter.html`، والاختبارات تشغَّل بـ:

```bash
node scripts/test_ls_generator.js
```

## الخيارات

- **اللغة (1):** English / العربية / متعددة اللغات مع لغة أساسية من 6 لغات (الإنجليزية، العربية، الفرنسية، الألمانية، الإسبانية، التركية) ولغات إضافية.
- **المحرك (2):** pdfLaTeX / XeLaTeX / LuaLaTeX، وطريقة دعم العربية: Arabi أو ArabTeX مع pdfLaTeX (مع خيار التشكيل)، وPolyglossia أو Babel مع المحركات اليونيكودية.
- **الوثيقة والصفحة (3):** 8 أنواع (article، report، book، letter، beamer، وKOMA: scrartcl، scrreprt، scrbook)، حجم الخط حسب النوع، الورقة والاتجاه والهوامش والأعمدة والطباعة والتباعد، ونسبة الشريحة وسمة العرض لـ beamer — مع أيقونة لكل خيار في القوائم المنسدلة.
- **الخطوط (4):** خط لاتيني وعربي جنبًا إلى جنب لكل دور (Roman / Sans Serif / Typewriter) بقوائم مختلفة لكل محرك، وخيار الأرقام (هندية/لاتينية) مع Polyglossia.
- **الحزم (5):** 32 حزمة في 7 مجموعات، بعضها يتعطل تلقائيًا حسب المحرك أو نوع الوثيقة، وsetspace تُفرض مع التباعد، وحصرية biblatex/natbib.
- **المحتوى (6):** العنوان والكاتب، نص تجريبي، صفحة عنوان، ملخص، فهرس.
- **هيكل المشروع (7):** متاح لأنواع report وbook ونسختيهما في KOMA (scrreprt وscrbook) فقط — ملف واحد أو مشروع متعدد الملفات (style.sty + frontmatter/ + chapters/ + appendices/ + backmatter/ + bib/) مع تنزيل ZIP، ومع الأنواع الأخرى يظهر القسم كإشعار يوضح ذلك.

## ملاحظات تقنية

- اسم ملف `.tex` ثابت الامتداد: يُكتب الاسم فقط في حقل «اسم الملف» واللاحقة `.tex` لاحقة ثابتة تُلحق عند التنزيل، مع تنظيف تلقائي للرموز الممنوعة.
- ملف `.tex` الناتج يبدأ بتعليقات `% !TeX program` و`% !TeX encoding`، وأقسام المقدمة موثقة بتعليقات فاصلة.
- أمر الترجمة المعروض يشمل سلسلة biber/bibtex الكاملة عند الحاجة.
- **ZIP** يُبنى عبر مكتبة **JSZip 3.10.1** موردة محليًا في `assets/js/vendor/jszip.min.js` (ضغط DEFLATE بمستوى 6، بلا اتصال شبكي، وتُحمَّل قبل main.js)، وتم التحقق من صحة مخرجاتها بأداة `unzip`.
- **الخطوط:** تُحمَّل من Google Fonts مع بدائل نظامية كاملة عند العمل دون اتصال.
- **تلوين الكود:** مُلوِّن LaTeX مكتوب يدويًا (تعليقات/أوامر/أقواس) بنفس نمط الأصل.

## الفروقات عن الأصل (Next.js)

| الأصل | هذه النسخة |
|---|---|
| Next.js + React 19 + TS | JavaScript نقي، الحالة كائن `cfg` واحد وإعادة بناء للواجهة |
| Tailwind 4 + shadcn | `style.css` + `responsive.css` نقيان بنفس ألوان oklch ونقاط الانكسار |
| fflate لبناء ZIP | مكتبة JSZip موردة محليًا (`assets/js/vendor/`) |
| Google Fonts عبر next/font | وسم `<link>` مع بدائل نظامية |
| @vercel/analytics | حُذف (لا تتبع إطلاقًا) |

منطق توليد LaTeX منقول حرفيًا (`resolveConfig`، `normalize`، `generate` في `assets/js/main.js`) ويغطيه 97 اختبار Node ناجح.
